# C++ DataFrame Operations

This repository contains a C++ assignment focused on implementing a simplified DataFrame structure with support for column manipulation, horizontal stacking and join operations.

The project was developed as part of a university programming course on algorithms and computational methods, with the objective of practicing object-oriented programming, data structures and table-like data manipulation in C++.

## Main objectives

- Implement a custom DataFrame structure in C++
- Manage sparse columns using associative containers
- Perform horizontal concatenation of datasets (`hstack`)
- Implement join operations between DataFrames
- Practice object-oriented programming and modular design
- Work with vectors, maps and structured data manipulation

## Repository structure

- `Column.h` / `Column.cpp`  
  Definition and implementation of the Column class.

- `DataFrame.h` / `DataFrame.cpp`  
  Definition and implementation of the DataFrame structure and its operations.

- `main.cpp`  
  Main program used to test DataFrame functionalities.

- `checkChallenge.h` / `checkChallenge.cpp`  
  Validation and testing utilities.

- `TestValues1.h` to `TestValues4.h`  
  Example datasets and predefined test cases.

- `outputsamples/`  
  Sample outputs generated by the program.

- `CMakeLists.txt`  
  Build configuration for compiling the project with CMake.

## Main functionalities

The project implements:

### Sparse column representation

Columns are internally represented using `std::map`, allowing sparse storage of values.

### Horizontal stacking (`hstack`)

Two DataFrames can be concatenated horizontally by appending columns side-by-side.

### Join operations

The project supports join operations between DataFrames using matching column values.

### Table manipulation

The DataFrame structure supports row and column handling together with formatted output visualisation.
